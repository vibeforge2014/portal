# Product preview artwork

`chargepilot-dashboard.jpg` is an unchanged copy of the existing ChargePilot
website asset `chargepilot-site/public/images/chargepilot-dashboard-real.jpg`.
It shows the actual Chinese interface at 960 × 720. Reused in the portal hero
and featured product card; no product UI or telemetry was fabricated.

Preview metadata and translated alternative text are in
`src/data/product-previews.ts`, keyed by product ID independently of CMS order.
The remaining products use their managed icons and compact text cards.
