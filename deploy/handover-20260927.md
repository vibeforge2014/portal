## 已知坑（都修过，别再踩 / 别删修复）

- `next build` 多 worker 并发开库 → `journal_mode = WAL` 立即 SQLITE_BUSY（不走 busy_timeout）：`src/lib/db.ts` 已 try/catch 容忍（12f9f86）
- Mac 构建链 `build-linux.sh` 换 x64 sharp 后必须补 `sharp/node_modules/semver`（脚本已处理），否则 `/api/media` 整体 500
- ISR 回写：主 systemd `ReadWritePaths` 必须含 `/opt/zensoft`；Docker 挂载绝不能 `:ro`——否则每分钟刷 EROFS 且页面缓存永不刷新
- Cloudflare 邮箱混淆会在水合前改写页脚邮箱文本 → React #418：`SiteShell.tsx` 邮箱锚点的 `suppressHydrationWarning` 不能删
- 媒体 URL 一律 `mediaUrl()`（`src/lib/media.ts`）生成，手拼会因 `trailingSlash: true` 白付 308
- `deploy-portal.sh` 曾丢可执行位（已随 12f9f86 修回 git）；再遇 permission denied 先 `chmod +x`
